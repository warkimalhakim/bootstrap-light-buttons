## Bootstrap Light Buttons

Style tambahan untuk project kamu yang menggunakan Bootstrap CSS Framework, meng-kusom button dengan gaya cerah.

**Requirement**

- Bootstrap versi 4 atau terbaru (https://getbootstrap.com)

## Penggunaan

Sertakan file css ini ke project, kemudian gunakan class buttons seperti di Bootstrap dan tambahkan \*-light pada akhir class tersebut. Contohnya menggunakan class `.btn-success` maka:

    <button type="button" class="btn btn-success">.btn-success Bootstrap</button>
    menjadi
    <button type="button" class="btn btn-success-light">.btn-success Bootstrap</button>

## Classes

semua class buttons yang ada pada Bootstrap sudah bisa digunakan, ganti dengan class ini:

- [x] .btn-primary-light
- [x] .btn-secondary-light
- [x] .btn-success-light
- [x] .btn-warning-light
- [x] .btn-danger-light
- [x] .btn-w-light
